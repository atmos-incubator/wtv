Wtv

Ad pictures

Pick a folder of images to show while ads play. Without one, Wtv uses its built-in cats. Name files like grumpy_d10s.png to show them for 10 seconds (default 5s). 

images/                  every site
  relax.png
  cats/                  [img cats]
  youtube.com/           only on YouTube, checked first
    grumpy_cats_d10s.png
    birds/               [img birds] on YouTube

    A keyword folder here lets the picked folder hold only keyword folders. A site’s own folder still comes first; top-level files are the fallback.
