        Format 
        [ads]                      ← before the first URL: every entry
  20: Take a moment to breathe   (quote, 20 seconds)
  [img cats]                     (pictures matching "cats")

https://www.youtube.com/watch?v=abc | Some Title | t=1:37
[ads]                      ← after a URL: only that entry
  [img]                          (this site's pictures)
  [img cats 10]                  (10 seconds each)

# comments start with # or //

[view pictures]            ← before the first URL: pictures cover every entry
[show]                     ← the pictures to show (like [ads])
  [img beach]
https://radio.example/live | Radio | view=pictures

https://example.com/story | view=read    ← the article, read out on screen
https://example.com/page  | view=scroll  ← the page itself, scrolled
https://x.com/someone/status/123 | view=card | dur=20s   ← a post, on a title card
[speed 200 wpm]            ← before the first URL: reading pace (also [speed 40 px/s])

[shuffle]                  ← before the first URL: random order
https://www.youtube.com/watch?v=abc | t=1:00 | end=2:30
https://www.youtube.com/watch?v=def | t=30 | dur=45s
[loop]                     ← after the last URL: start again

        Each line is a URL (with an optional | title and | t=1:37 start time), an [ads] block, a quote (N: text), a picture item ([img keyword N]), or a comment. Indentation is up to you. Start times: 97, 1:37, 1h2m3s.

        view=pictures on an entry (or [view pictures] before the first URL) plays it unseen behind pictures, for music, radio and podcasts. The pictures come from a [show] block (the entry's, else the playlist's), else its [ads], else the site's pictures. view=video turns it off for one entry.

        Pages and posts: view=read shows a page's article as large text, scrolled at a reading pace (speed=200 words per minute); if there's no article it scrolls the page instead. view=scroll scrolls the page itself to the bottom (speed=40 pixels a second). view=card shows a post (X only, so far) on a title card. They end at the bottom (or the card's time), or after dur=. [speed 200 wpm] / [speed 40 px/s] before the first URL set the playlist's pace.

        end=2:30 stops an entry at that time; dur=45s plays it that long from its start. Ads don't count towards either. [shuffle] and [loop] tick the Shuffle and Loop boxes by default; a shuffled loop reshuffles every lap.
